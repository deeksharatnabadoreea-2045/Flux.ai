# Build pact — engine progress → co-pilot power

You work on making **in-silico trial software doable**. As each stage is **proven**, we upgrade the **scientist co-pilot** (chat + desks)—not before.

## How we work together

1. **You ship proof** (data, replay, code, metrics)—even small.
2. **You tell this chat** what landed (or open a brief on HQ).
3. **We merge co-pilot features** that match that proof—chat flows, tools, templates, docs.

No feature gets marketed beyond what the last stage supports.

## Stages

| Stage | You build | Co-pilot gains |
| --- | --- | --- |
| **L0** *(live)* | Registries, one disease/outcome | Scout chat + linked sites |
| **L1** *(next)* | Guess past trial outcomes correctly | “Did we get it right?” from chat |
| **L2** | Repeatable pipeline | Back-test bundle from chat |
| **L3** | Clear pass/fail rules | Go / wait / kill scorecard |
| **L4** | Side-by-side with live trial | Sponsor shadow tracker |
| **L5** | Audit-ready validated slice | Premium evidence export |

Machine-readable: `js/copilot-roadmap.js`.

## What to send when you progress

- What disease / outcome
- Which trial IDs
- What ran (repo path or script name)
- One number: how often you matched reality

That is enough to unlock the next co-pilot slice.
